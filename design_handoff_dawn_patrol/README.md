# Handoff: Dawn Patrol — Sydney Eastern Suburbs Surf Dashboard

## Overview
A phone-first single-page app that ranks five Sydney Eastern Suburbs beaches (Bondi, Tamarama, Bronte, Coogee, Maroubra) by a computed 0–10 surf score, with a 5-day outlook per beach, a persistent skill-level toggle that re-weights scoring live, pinnable favourite beaches, and a "best window in the next 48 h" callout.

Target repo: `nicolasletoublon/surfcheck` (currently empty). Target stack per `original-build-prompt.md`: **React 18 + Vite, deployed to GitHub Pages, no backend, keyless Open-Meteo APIs called from the browser.**

## About the Design Files
The files in this bundle are **design references created in HTML** — a working prototype showing intended look, behavior, and scoring logic, not production code to copy verbatim. The task is to **recreate this design as a React 18 + Vite app** following `original-build-prompt.md` (which is the authoritative product spec: APIs, caching, deployment workflow, README).

Two exceptions are directly portable:
- **`beaches.js`** — beach config, scoring engine, formatting helpers. The `BEACHES`, `SKILLS`, `scoreHour`, `scoreLabel`, `whyLine`, `wetsuit`, `compass`, tide helpers and `buildModel` shape are meant to be lifted into `src/` nearly as-is. Replace the mock generator (`hourAt`, `WIND_DAYS`, `TIDE`, `sun`) with real Open-Meteo responses (URLs in the prompt); keep the scoring functions.
- The CSS custom properties below are final design tokens.

## Interactions & Behavior
- Card click → open bottom sheet (day resets to Today). Scrim click → close.
- Skill toggle → recompute every score, re-rank cards (favourites still pinned), update best window, day pills and charts. Persisted.
- Star click → toggle favourite, re-sort immediately, persist.
- Day pill click → chart + title swap for that day.
- Direction arrows rotate to real bearing; they point **where the wind/swell is going** (from-bearing + 180°); text label shows the from-compass point.
- "Firing" score treatment: animated gradient shimmer — `linear-gradient(90deg,#ff7a59,#ffb84d,#ff5db1,#ff7a59)`, background-size 200%, background-clip text, transparent color, keyframes shifting background-position 0%→200% over 2.6s linear infinite.
- Animations: sheet slide-up (translateY 48px→0 + fade, .3s), scrim fade (.25s). Card hover lift.
- Loading: skeleton cards while the 10 fetches resolve (per prompt); per-beach error card with retry on fetch failure.
- Theme: follows `prefers-color-scheme` (dark + light token sets below), with optional manual override.

## State Management
- `skill` ('Beginner' | 'Intermediate' | 'Experienced') — localStorage `dp-skill`.
- `favs` (beach-id array) — localStorage `dp-favs`.
- `sheetId` (beach id | null), `day` (0–4).
- Fetched marine+forecast responses per beach — cache in localStorage 30 min with fetch timestamp (drives "updated X min ago").
- Everything else derives from those via `buildModel(skill, now, baseDate)`.

## Scoring (in `beaches.js`, keep as-is)
Weighted 0–10: wind 0.35 (offshore ≈ facing+180°, ≤55° = offshore, ≤115° cross, else onshore; speed penalties scaled by skill), size 0.20 (gaussian around skill band center: 0.85 / 1.5 / 2.2 m of *effective* height `swellH × √(period/10)` × beach exposure), direction/exposure 0.25, period 0.10 (<7 s penalised, ≥11 s groundswell bonus), tide 0.10 (mid best). Break height < 0.35 m caps score at 1.6 (Flat); < 0.55 m caps at 4.5. Labels: <2 Flat, <4 Poor, <7 Fair, <8.5 Good, ≥8.5 Firing.
